Nodeau Home

Put the GPU you already have to work.

If your PC has a compatible NVIDIA GPU, Nodeau handles the infrastructure that turns it into a usable local AI endpoint.

Owning a GPU is not the same as having AI infrastructure. Drivers, runtimes, model formats, quantisation, memory limits, containers, model servers, authentication — none of that is why you wanted to run a model. Nodeau does that part.

Install Alpha Read the FAQ

It checks the machine first

Operating system, GPU, driver, disk. If something is missing it says what, and stops before changing anything.

It works out whether the model fits

Nodeau compares what your GPU can actually give a workload against what the model needs — and refuses, with the arithmetic, rather than letting it fail at load time.

It downloads and verifies the model

Fetched from the publisher over HTTPS and checked against a known SHA-256 before anything runs it. Cached locally, so it is fetched once.

It gives you an ordinary API

OpenAI-compatible, on 127.0.0.1, with a locally generated key. Existing SDKs work by changing the base URL.

And it can undo itself

Nodeau records what it installed as distinct from what was already there, so uninstall removes only its own work.

Four steps

From a spare GPU to a local endpoint.

The whole flow is three commands and a request. The long part is downloading the model.

Nodeau Business

GPU infrastructure for teams that own the hardware.

Make the GPUs your organisation already owns easier to operate as shared AI infrastructure.

Organisations accumulate GPUs faster than they accumulate ways to run them: developer workstations, a lab server, an edge box, three generations of hardware. Owning them does not produce scheduling, capacity awareness, placement, or any view of what is running where.

That control plane is the direction Nodeau Business is built towards. The foundation exists today on a single node; the fleet-level work is deliberately labelled as roadmap rather than described as shipping.

How it decides

A scheduler should know more than “GPU: 1”.

Generic infrastructure mostly knows that a GPU exists. That is enough to place a workload and not enough to know it will survive.

Nodeau reasons about what the card can actually give this workload: the memory CUDA can address, what is already in use outside Nodeau, what Nodeau has itself reserved, a safety reserve, and what the model has been measured to need. Then it admits the workload — or explains why it will not.

The control plane is deliberately not in the inference path. It decides placement and manages lifecycle; requests go straight to the model runtime. Restarting the control plane does not interrupt inference.
