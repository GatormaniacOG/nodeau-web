Stuck on something?

Run nodeau support bundle and attach the file it writes. It's scrubbed of keys and credentials and holds no prompts or model output. If setup stopped before the CLI worked, send ~/.local/state/nodeau/install.log instead.

Save yourself the evening of fixing it by hand. Send it to us and we'll fix Nodeau.
